## 📌 Project Description

This project is a **Digital Image Processing application developed in Python**.
It allows the user to analyze a color image and perform several operations such as:

* Extract RGB components
* Convert image to grayscale
* Generate histograms
* Save processed images
* Compress image using Huffman coding

The program reads an image named **img.jpg** and processes it automatically.

---

## ⚙️ Features

### 1️⃣ Image Loading

The program loads an image file:

```
img.jpg
```

The image is converted into a numerical matrix using **NumPy**.

---

### 2️⃣ RGB Extraction

The program separates the image into three color channels:

* Red Channel
* Green Channel
* Blue Channel

The values are saved into text files:

```
files/rouge.txt
files/vert.txt
files/blue.txt
```

---

### 3️⃣ Grayscale Conversion

The program converts the image into grayscale using three methods:

### ✔ Method 1 – Recommendation 709

Standard grayscale conversion formula.

Saved in:

```
files/R709.txt
```

---

### ✔ Method 2 – Recommendation 601

Another standard grayscale conversion.

Saved in:

```
files/R601.txt
```

---

### ✔ Method 3 – Simple Method

Average of RGB values.

Saved in:

```
files/MethodeSimple.txt
```

---

### 4️⃣ Histogram Generation

The program generates histograms for:

* Recommendation 709
* Recommendation 601
* Simple Method

Histograms show the distribution of pixel intensity.

---

### 5️⃣ Image Saving

Generated grayscale images are saved as image files:

```
Recommandation709.png
Recommandation601.png
MethodeSimple.png
```

---

### 6️⃣ Huffman Compression

The program applies **Huffman compression** to reduce the data size.

The compression is applied to the grayscale image generated by the simple method.
